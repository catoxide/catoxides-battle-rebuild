## 1. 三系模型（本次修正的核心认知，源码+实测校准）
Spark 解析时存在 **文件系 → 内部系** 的全局转换（verify_pose_v3.js 头注，与 ModelModule/
OBoneAnimation/BonePose 源码一致；verify_pose 已用旧 build 复现用户"指向右侧"观测 ⇒ 约定可信）：

| 量 | 文件系 → 内部系 |
|---|---|
| 骨 pivot / cube pivot / 动画 position | (x,y,z) → (−x, y, z)（仅 X 取反） |
| cube origin | (ox,oy,oz) → (−(ox+sx), oy, oz)（min-corner 翻转） |
| 骨/cube/动画 rotation | (rx,ry,rz)° → 内部矩阵 Rz(rz)·Ry(−ry)·Rx(−rx) |

**内部系 = 实际渲染系：+X 玩家右 / +Y 上 / +Z 玩家前**（文件系 +X = 玩家左）。
旧 build 剑轴复现 = 内部 (1,0,0) = 玩家右 ⇒ 用户观测"指向右侧"精确复现 ✓。
