ContentPack 生成器（网页版）

产出可直接构建的内容包：MANIFEST.MF（全属性）+ build.gradle（Gradle 子项目骨架） + 入口类骨架 + entities/*.json。
下载的 zip 顶层目录就是包名，解压到 contentpacks-source/ 即可（无需改 settings.gradle，自动发现）。
完整可视化编辑（模型 / 部位 / 结构）请用 tools/contentpack-editor（Electron 版），本页是零安装的最小生成器。

包设置（MANIFEST）

包间依赖禁止版本区间（写了会被加载器忽略并告警）；入口类不能放在 com.catoxide.catoxidesbattlerebuild.*（该前缀永远交给父加载器，看不到包内类）。

实体定义

纯资源/数据包可以不添加实体——但此时不要填 Module-Entry（无代码是合法用法）。

预检与生成

产物与后续

① 下载 zip → 解压到 contentpacks-source/（得到 contentpacks-source/<包名>/）
② 构建：gradlew :packs:<包名>:contentpackJar → 产物 contentpacks/<Module-Name>.jar （也可 gradlew contentpackJar 构建全部包）
③ 产物按 Module-Name 命名：改名/弃用的旧 jar 必须手工删除，否则同 Module-Name 重复， 加载哪个取决于扫描顺序
规范：design/CONTENTPACK_FORMAT.md §2/§9、design/GRADLE_MULTIPROJECT.md §2.3
